StremioNative

An unofficial native Stremio client for LG webOS TVs: hardware playback, your addons, Dolby Digital and Pro Logic II audio conversion, Dolby Vision and styled subtitles.

Install with Homebrew Channel

  1. Install Homebrew Channel on the TV (a rooted TV is recommended).
  2. In Homebrew Channel, open Settings → Add repository and enter:
  3. Install StremioNative or StremioNative Beta from the list. Updates arrive the same way.
